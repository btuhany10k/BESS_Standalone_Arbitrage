# Project Rules

## Frontend & UI Design Directives
- **Default Frontend Skill**: Always activate and follow the `design-taste-frontend` skill by default whenever writing, modifying, or reviewing any frontend code, Streamlit dashboards, HTML/CSS, Tailwind, or interactive UI components.
- **Standards**:
  - Calibrated neutral color palettes with at most 1 accent color (avoid AI-purple / generic neon).
  - Responsive layout safety (`min-h-[100dvh]` over `h-screen`).
  - High-agency typography, clean data display without over-boxing into unnecessary cards.
  - Complete UI interaction states (loading skeletons, empty states, tactile button feedback).
